# 悬赏终端 · Bounty Terminal

毛玻璃悬赏看板。一眼看清**当前悬赏 / 倒计时 / 抢单**，顺手看**排行榜**和**赏金猎人墙**。

它是工作台的独立前端镜像：读写都走工作台的 HTTP API，自己不存数据、不改状态机——真值永远在工作台里。

## 功能

- **当前悬赏**：内容、积分、状态（未开放 / 开放中 / 已被抢到）、服务端口径倒计时（每秒刷新，用服务端时间和本地时间对齐，不信任本机时钟）
- **抢单**：`POST /站长_to_all_悬赏`，开放时刻之后第一个抢到的算赢，毫秒级滞后由服务端计算
- **抢单排行榜**：按「抢到次数」排，次数相同看累计积分；第一名戴皇冠
- **赏金猎人墙**：抢到过悬赏的都上墙
- **发布悬赏**：写内容 + 积分 + 开放时刻，一键发布 / 一键撤下
- **历史战绩**：最近 40 条抢单记录
- **6 套主题**：极光 / 翡翠 / 日落 / 兰花 / 海洋 / 玫瑰，纯色相旋转，玻璃质感不变；选择记在 localStorage

## 运行

```sh
python app.py
```

打开 <http://127.0.0.1:6001>

只需要 Python 3 标准库，无第三方依赖。

## 配置（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `DSH_XS_PORT` | `6001` | 本看板端口（**别用 6000：Chromium 内核封锁**）|
| `DSH_XS_WORKBENCH` | `http://127.0.0.1:5001` | 工作台地址 |
| `DSH_XS_BOUNTY_PATH` | `/api/bounty` | 悬赏查询/发布路径 |
| `DSH_XS_GRAB_PATH` | `/站长_to_all_悬赏` | 抢单路径 |

> 工作台不在本机、或改过路由名时，用这几个环境变量指过去即可，代码里没有写死。

## 本地代理路由

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/` | 看板页面 |
| GET | `/api/bounty` | 转发工作台的悬赏 + 战绩 |
| POST | `/api/bounty` | 转发发布 / 撤下 |
| POST | `/api/grab` | 转发抢单 |
| GET | `/api/meta` | 工作台地址、服务端时间 |
